一款集环境监测、信息交互与智能控制功能的简易智能镜，探索嵌入式与物联网技术在智能家居场景中的应用。

- **系统集成与 PCB 设计**：STM32F4 系列微控制器为主控，完成温湿度传感（DHT11）、蓝牙通信（HC-05）、1.8 寸 TFT 屏幕及语音模块的多层 PCB 设计，优化高速信号走线，提升抗干扰能力。
- **智能交互逻辑**：集成离线语音识别模块，结合「打开灯光」「查询天气」「切换模式」等十余条核心指令集，识别准确率提升至 95%；通过 AT 指令集驱动 Wi-Fi 模块调用第三方 API 获取实时天气与时间。
