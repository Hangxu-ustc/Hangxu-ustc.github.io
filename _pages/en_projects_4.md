A simple STM32-based ultrasonic radar for measuring obstacle distance with real-time display.

- Built the hardware with an HC-SR04 ultrasonic sensor and an STM32F103C8T6 MCU.
- Wrote C firmware for sensor data acquisition and distance computation, with an LCD module showing the results in real time.
